\section*{Cleveref}
\noindent
\verb!\cref{lem:my-lemma}! to refer to \cref{lem:my-lemma}.\\
\verb!\cref{sec:section-title}! to refer to \cref{sec:section-title}.\\
\verb!\cref*{sec:section-title}! to avoid creating hyperlinks $\longrightarrow$ \cref*{sec:section-title}.
\medskip

\section*{Code}

% Both code samples should use the same monospaced font with every engine.
\verb|\texttt{file\_name}| uses the monospaced font; special characters need escaping $\longrightarrow$ \texttt{file\_name}.\\
\verb|\verb!file_name!| prints special characters literally $\longrightarrow$ \verb!file_name!.\\
\verb!\cd{code}! to use the inconsolata $\longrightarrow$ \cd{code}.\\
\verb!\fncd{code}! to use the inconsolata in footnotes $\longrightarrow$ \fncd{code}.\\
\medskip

\section*{Diamond}

Use \verb!\diam! to add a diamond symbol at the end of a line:

(used for examples sections) \diam

\noindent To color the box, pass the options \verb!box-border=<color>! and \verb!box-background=<color>! to the package. The colours must be defined in xcolor or with \verb!\definecolor!. Default colours are \verb!box-border=black! and \verb!box-background=white!.

\section*{SIUnit}

Use the \verb!siunitx! package to typeset SI units and numbers.\\The following examples demonstrate the usage:\\

\noindent
\verb!\SI{10}{\meter}! $\longrightarrow$ \SI{10}{\meter}.\\
\verb!\num{10}! $\longrightarrow$ \num{10}.\\
\verb!\unit{\kilo\gram\metre\per\square\second}! $\longrightarrow$ \unit{\kilo\gram\metre\per\square\second}.
